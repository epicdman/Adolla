Privacy Policy

Effective September 30, 2026 · Adolla, Tempe, Arizona

This policy covers adolla.business and Pulsar, the internal tool Adolla uses to run its own YouTube channels and business accounts. Pulsar is used only by Adolla, on Adolla's own Google accounts. It is not offered to the public, and it never signs in to anyone else's account.

This website

adolla.business is a static site. It doesn't use cookies, analytics, ads or trackers, and it has no sign-up or forms. If you email us, we use your message and address only to reply.

Google data Pulsar accesses

When Adolla signs in to Pulsar with Google, it asks for these permissions:

PermissionWhat Pulsar does with it
youtube.uploadUploads finished videos to Adolla's own channels.
youtube.force-sslSets and updates the titles, descriptions, thumbnails, privacy settings and publish times of those videos, and reads basic stats for them.
calendar.readonlyReads Adolla's own calendar so scheduling works around events that are already booked. It never creates, edits or deletes calendar events.
gmail.modifyCreates email drafts in Adolla's own mailbox, sends them only after a person approves them, and reads replies to that email. The only thing it ever deletes is its own unsent drafts.

How it's used and stored

  • Data from Google is used only to provide the features listed above, for Adolla's own accounts.
  • It's stored on Adolla's own computer. Sign-in tokens are kept in local files that aren't shared or uploaded anywhere.
  • When Pulsar drafts a video description or an email reply, the relevant text may be sent to an AI service we use to write the draft. That's only to produce the draft, and a person reviews it before anything is sent or published.
  • We don't sell Google user data, use it for advertising, or let anyone read it except when needed for security, to comply with law, or with the account owner's permission.
  • We don't use Google user data to train or improve AI or machine-learning models.

Google API Services User Data Policy

Adolla's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

Pulsar uses YouTube API Services. By using Pulsar you agree to be bound by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Keeping and deleting data

Data Pulsar keeps is removed when it's no longer needed for the features above, and all of it can be deleted on request. Access can be revoked at any time at Google's security settings page, and YouTube access specifically via the same page. Revoking access stops Pulsar from reaching the account immediately.

Children

Neither this site nor Pulsar is directed at children under 13, and we don't knowingly collect their information.

Changes

If this policy changes, the new version will be posted here with a new effective date.
